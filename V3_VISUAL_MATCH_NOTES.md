# Reel It Operations v3 — White Mock Match

This build intentionally follows the approved white dashboard mock much more closely while keeping the existing Firebase-backed operations functionality.

- White 220px left navigation rail
- Compact Owner Desk card
- Overview title with date / filter / refresh controls
- Search bar in the same top-right zone as the approved mock
- Five compact KPI cards
- Booking filter tabs across the table header
- Dense operational booking table
- Table footer / pagination treatment
- Fixed right-side 390px Control Room drawer

- Firestore live operational data
- Booking search and short RIT references

- Files and timeline tabs
- Force end → Pending upload
